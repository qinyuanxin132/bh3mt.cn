## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## CTF Reverse Learning Archive

Personal CTF Reverse learning profile, roadmap, active progress board, and logs live in `docs/re-learning/` (excluded from Astro blog posts).

When assisting with CTF Reverse learning, planning, or practice:
- Read `docs/re-learning/README.md`, `docs/re-learning/PROGRESS.md`, and `docs/re-learning/PROFILE.md` first.
- Update `docs/re-learning/PROGRESS.md` and `docs/re-learning/LOG.md` after finishing exercises or assessments.
