# 泠的静态 Live2D 看板娘

## 运行方式

全程浏览器运行。GitHub Pages 直接提供 JS、模型、纹理、物理和动作文件，不需要 Node 服务、桌面 EX、摄像头或麦克风。

- 组件：`src/components/LingLive2D.astro`，由公共布局引入。
- 生命周期与交互：`src/scripts/ling-live2d.ts`。
- 模型入口：`public/live2d/ling-v16/ling.model3.json`。
- 运行核心：`public/vendor/live2d/live2dcubismcore.min.js`，来自官方 Cubism Core 5.2 URL。来源、版本与校验值保存在同目录 README。
- 渲染器：锁定 `pixi.js@6.5.10`、`pixi-live2d-display@0.4.0`。Cubism Core 5.3 改了 render-order API，不能直接替换已固定的 5.2 核心。

## 模型来源与适配

作者提供的 `Ling_Live2DViewerEX_v16/Ling_EX_v16/` 中桌宠入口 `Ling_Desktop.model3.json`。

保留原始 `Ling.moc3`、两张 PNG 纹理、`Ling.physics3.json`、显示信息、四组表情与原始动作，网页实际引用资源约 25.5 MiB。未复制面捕入口、面捕重复模型和对比视频。模型文件均小于 GitHub 单文件上传上限，不需要 Git LFS。

网页入口去掉 EX 专用的 `Controllers`、`Options` 和碰撞区域扩展字段；网页控制器复现温和鼠标跟随范围，保留原始模型与物理，不重画角色。以后更换模型要同时检查 model3.json 引用路径与大小写。

## 行为

- 宽屏（至少 1280px）鼠标设备默认在首次空闲时加载；窄屏、减少动态效果偏好、省流模式默认收起，点击“召唤泠”才加载。
- JS 渲染依赖、Cubism Core、模型纹理均按需加载、同源提供，不依赖运行时第三方 CDN。
- 可在工具栏互动、轮换微笑/惊讶/难过/生气/默认表情、暂停/继续、收起。
- 透明画布区域穿透鼠标；身体网格响应滚轮与双击，脸/狐耳/眼睛响应点击。原生按钮、链接、表单不会被全局点击误触。
- 拖动“⠿ 泠”调整位置；聚焦该按钮后方向键微调，Shift 加大步幅。窗口变化后约束到可见范围。
- 默认桌面展示区增大至 250 × 400px，手机为 190 × 300px（随可用高度调整）。鼠标位于模型身体网格时滚轮缩放；透明边缘保留正文滚动，Ctrl / Command + 滚轮保留浏览器操作。
- 尺寸栏提供缩小、放大、百分比复位；浮动模式缩放范围 65%–240%，实际尺寸受视口限制，避免控制按钮移出屏幕。
- 双击身体或点击“橱窗”进入大尺寸原生对话框，复用当前画布与模型，无需重新下载；橱窗独立缩放 65%–200%，以脸部为缩放中心，并为狐耳预留上方空间。Esc、右上角关闭、背景或“返回伴读”退出，恢复原位置、尺寸和焦点；手机可用尺寸栏操作。
- localStorage 键 `bh3mt:ling-live2d:v1` 保存展开状态、拖动位置、浮动缩放比例与待机预设，禁止存储时也可运行。
- 独立 30 FPS ticker，像素比最高 1.5；收起、暂停、切换到后台时停更；离开页面释放 WebGL 和模型资源。
- 无 WebGL、加载失败时显示静态形象与重试按钮，不影响博客功能。

## 验证

本地：`npm run build`；开发服务按 AGENTS.md 使用 `npm run dev -- --background`。

重点检查宽屏自动加载、手机默认零模型请求、手动展开、收起记忆、动作/表情加载、拖动与缩放窗口、身体滚轮缩放与透明区域滚动、双击橱窗及 Esc / 按钮退出、尺寸记忆、后台暂停、WebGL 失败重试。上线后确认 `/live2d/ling-v16/ling.model3.json` 及其所有引用路径同源返回成功。

## v16 待机与动作

点击看板娘下方“待机与动作”，可选择 6 个预设：轻柔陪伴、安静阅读、专注写码、放松小憩、轻轻招呼、橱窗展示。轻柔陪伴有两种变化，共 7 个 36 秒待机变体；保留原待机的自然眨眼节奏，加入小幅呼吸、轻微重心与低位手腕变化。非循环 motion 结束后，由动作管理器继续当前预设，互动结束也返回当前待机。预设记忆兼容原有 localStorage。

8 个单次动作：点头、左右侧耳、左右单眨、左右耳轻动、舒缓呼吸；“互动”按钮也可依次轮换。“恢复轻柔”重置待机与表情，缩放和拖动位置保持不变。暂停、收起、后台停更沿用原逻辑，不增加额外的动画定时器。

原动作保存在 v16 目录。`scripts/prepare-ling-v16.py` 从这些原始 JSON 生成 `web-*` 低幅度变体；`SOURCE.json` 记录原始模型、纹理、物理、表情和动作的 SHA256。浏览器仅加载 v16 版本目录，避免旧缓存混入新模型；旧目录暂留给已缓存的旧页面使用，不会同时加载两个模型。

`src/data/ling-live2d.ts` 定义预设、动作及最终参数约束。`beforeModelUpdate` 在动作、表情、跟随和物理计算后执行限幅及速度限制：头部 X ±8°、Y ±4°、Z ±3°，身体角度约 ±1°，重心 ±0.25；手腕横移 ±0.10、抬落 −0.12～0.16、摆腕 ±0.12；狐耳姿态 ±0.30、耳尖 ±0.25；头发物理参数 ±0.30。限制最终实际渲染值，防止多个通道叠加后超出范围。保留正常快速眨眼，不使用过顶举手、手捕、面捕或语音设置。

更新模型时保留原资源，然后运行 `python3 scripts/prepare-ling-v16.py` 重建动作。不要直接把 EX 的控制器或动作幅度套到网页。

检查：`node scripts/check-live2d.mjs` 验证来源哈希、所有引用、动作计数、曲线控制点限幅与 Core 兼容；启动构建产物的本地 HTTP 服务后运行 `node scripts/check-live2d-browser.cjs`（默认 4322 端口，可设 URL / CHROMIUM_PATH）。浏览器测试通过测试专用 Core 注入采集实际渲染参数与顶点，覆盖整轮待机、6 个预设、8 个动作、单帧变化上限、暂停、脸部缩放橱窗、记忆和手机面板。测试注入不会写入生产运行库。
